# Building KVision on Windows

> **Note:** This build instruction was generated by an AI and has not been tested on a real Windows environment. Your mileage may vary, and you may need to adjust paths or dependencies manually.

This guide explains how to set up the development environment and build KVision on a Windows system.

## Prerequisites

1. **Qt 6**: Install Qt 6 (6.5 or newer is recommended) via the Qt Maintenance Tool.
   - Make sure to install the **MSVC 2019** or **MSVC 2022** compiler version (e.g., MSVC 2019 64-bit).
   - Also, install the **Qt 5 Compatibility Module** and **Qt Shader Tools** if available.
2. **CMake**: Install CMake (usually bundled with Qt Creator, but standalone is fine).
3. **Visual Studio**: Install Visual Studio 2019 or 2022 with the "Desktop development with C++" workload.

## Dependencies

KVision relies on a few external libraries which need Windows-compatible versions:

### 1. Hikvision SDK (CH-HCNetSDK)
The repository currently contains Linux shared libraries (`.so`). For Windows, you need the Windows SDK.
- Download the **CH-HCNetSDK (Windows 64-bit)** from the official Hikvision portal.
- Replace the contents of `src/hikvision_sdk/lib` with the Windows `.lib` files (e.g., `HCNetSDK.lib`, `PlayCtrl.lib`).
- Replace the contents of `src/hikvision_sdk/inc` with the Windows header files if they differ.

### 2. FFmpeg (QmlAV Dependency)
- Download Windows pre-built dev and shared binaries for FFmpeg (e.g., from gyan.dev or BtbN).
- You will need to update the `CMakeLists.txt` or configure CMake to find these Windows FFmpeg libraries (`avcodec.lib`, `avformat.lib`, `avutil.lib`, `swscale.lib`, etc.) instead of the Linux/Android paths currently hardcoded in `src/qmlav/CMakeLists.txt`.

## Build Instructions

### Using Qt Creator (Recommended)

1. Open **Qt Creator**.
2. Go to `File` -> `Open File or Project...` and select the `CMakeLists.txt` in the root of the KVision repository.
3. In the "Configure Project" screen, select your **Desktop Qt 6 MSVC 64-bit** kit.
4. Click **Configure Project**.
5. Once CMake finishes configuring, click the **Build** (hammer) icon in the bottom left.

### Using Command Line (CMake)

Open the **x64 Native Tools Command Prompt for VS** (from the Start Menu) and run:

```cmd
mkdir build
cd build
cmake -G "Visual Studio 17 2022" -A x64 -DCMAKE_PREFIX_PATH="C:\Qt\6.x.x\msvc2019_64" ..
cmake --build . --config Release
```
*(Adjust the Qt path `C:\Qt\6.x.x\msvc2019_64` to match your actual Qt installation directory).*

## Running the Application

To run the application successfully on Windows, all required DLLs must be placed in the same directory as the `kvision.exe` executable (e.g., inside the `build/Release` folder).

Ensure you copy the following DLLs to the executable directory:
- Qt6 DLLs (use the `windeployqt` tool to automate this):
  ```cmd
  windeployqt Release\kvision.exe
  ```
- FFmpeg DLLs (`avcodec-*.dll`, `avformat-*.dll`, etc.)
- Hikvision SDK DLLs (`HCNetSDK.dll`, `PlayCtrl.dll`, `HCCore.dll`, and all dependencies from the SDK package)

Once all DLLs are in place, double-click `kvision.exe` to launch the application.

## Troubleshooting

- **LNK2019 Unresolved External Symbol**: This usually means a `.lib` file is missing from the linker paths. Ensure that `target_link_directories` in `CMakeLists.txt` points correctly to your Windows `.lib` files for Hikvision SDK and FFmpeg.
- **Application crashes on startup (0xc0000135)**: A required `.dll` file is missing from the executable directory. Double-check that all Qt, FFmpeg, and Hikvision DLLs are next to `kvision.exe`.
